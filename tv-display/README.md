# TV 화면 코드

Python으로 화면 상태 데이터를 정하고 HTML 템플릿에 채웁니다. 별도 패키지 설치가 필요하지 않습니다.

## 실행

```bash
python app.py
```

실행한 위치와 관계없이 이 폴더에 `index.html`이 생성됩니다. 생성된 파일을 브라우저에서 열어 화면 디자인을 확인하세요.

## 예시 데이터 변경

`app.py` 상단의 세 값을 수정한 뒤 다시 실행합니다.

- `TV_CLASSROOM`: 이 화면을 표시할 교실
- `CURRENT_CLASS`: 현재 급식 중인 교실
- `NEXT_CLASS`: 다음 순서인 교실

예를 들어 모두 `1-2` 형식으로 지정합니다. 화면의 디자인은 `template.html`에서 수정합니다. `index.html`은 Python이 생성하는 결과 파일입니다.

이 프로토타입에는 Arduino 연결, 서버 통신, TV로의 네트워크 전송이 들어 있지 않습니다. 화면의 날짜와 시계는 생성 시점의 날짜 및 브라우저 기기 내부 시각을 사용합니다.
