# Arduino 기반 실시간 급식 순번 안내 시스템

- 기록일: 2026-10-19
- 참고 대화: https://chatgpt.com/share/6ad5d38b-0c38-83e8-98bc-51e2d277f43d

## 프로젝트 개요

급식 도우미가 Arduino에서 반을 선택하고 NEXT 버튼을 누르면, 메인 서버가 급식 순번을 갱신하고 교내 네트워크를 통해 각 교실 TV에 해당 반의 급식 상태를 표시하는 시스템이다. 휴대전화를 사용하기 어려운 학교 환경에서 기존 TV를 활용하고, 급식 도우미의 층별 이동과 직접 전달을 줄이는 것을 목표로 한다.

## 시스템 구성

```text
급식 도우미
    │ 반 선택 / NEXT
    ▼
Arduino 입력 장치
    │ USB 또는 Bluetooth
    ▼
메인 서버 (노트북으로 프로토타입 시작)
    ├── 오늘의 급식 순서와 현재 순번 관리
    ├── 현재 반과 다음 반 계산
    ├── 교실 TV별 반 설정 및 표시 상태 관리
    └── 상태 변경을 웹페이지에 전달 (WebSocket 고려)
             │ 교내 Wi-Fi / 유선 LAN
       ┌─────┼─────┐
       ▼     ▼     ▼
    교실 TV  교실 TV  교실 TV
     1-1      1-2      2-1
```

Arduino는 서버에만 입력을 전달한다. 급식 순서 계산과 상태 관리는 서버가 맡고, TV는 서버가 전달한 결과를 화면에 표시한다. 각 TV는 서버 페이지에서 자신의 교실을 설정해 반별 안내를 받을 수 있다.

## 화면 동작

서버는 급식 순서를 예를 들어 `[2-3, 1-2, 3-1, 2-1, 1-3]`처럼 저장하고 현재 순번을 관리한다. 급식 도우미가 실제 진행 상황에 맞춰 NEXT를 누를 때마다 현재 반과 다음 반을 갱신한다. 시간표에 따라 자동으로 넘어가는 방식이 아니므로 급식이 예상보다 빠르거나 느려도 현장 상황에 대응할 수 있다.

- 현재 급식 중인 반: “지금 이동하세요!”
- 다음 순서인 반: “다음 순서입니다. 준비해주세요.”
- 그 외 반: 대기 상태 및 현재 급식 반 안내

순번 변경은 처음에는 페이지 새로고침이나 주기적 조회로 구현할 수 있고, 이후 WebSocket으로 서버에서 여러 TV에 거의 실시간 전달하도록 확장할 수 있다.

## 실현 가능성과 주요 판단

- 스마트 TV의 내장 브라우저 또는 TV에 연결된 PC/미니 PC에서 웹페이지를 표시하는 방식은 실현 가능성이 높다. 실제 적용 전 교실 TV의 제조사·모델·브라우저 지원 여부를 확인하고 테스트 페이지를 열어봐야 한다.
- Arduino Bluetooth가 학교 전체의 여러 TV에 직접 연결되는 구조는 거리, 벽과 층, 간섭, 연결 대상 지원 문제 때문에 권장하지 않는다.
- Bluetooth를 쓴다면 우선 Arduino와 관리용 PC 사이의 입력 통신에 한정한다. 안정적인 통신 거리는 보드·모듈과 학교 환경에서 실측한다.
- 학교 네트워크에 개인 Arduino나 서버를 연결할 수 있는지는 학교 네트워크 정책을 확인해야 한다.
- 학교 TV가 브라우저를 충분히 지원하지 않으면 각 TV에 연결된 PC/미니 PC를 웹페이지 출력 장치로 사용할 수 있다.

## 단계별 프로토타입

1. **입력과 웹 상태 확인:** Arduino를 USB로 노트북에 연결하고 버튼 입력으로 웹페이지의 현재/다음 반이 바뀌는지 확인한다.
2. **Bluetooth 연결 확인:** USB 대신 Bluetooth를 적용하고, 급식실에서 관리 PC까지 거리와 위치별 안정성을 측정한다.
3. **서버 순번 관리:** 서버에 하루의 순서와 현재 인덱스를 두고 NEXT 입력에 따라 현재·다음 반을 갱신한다.
4. **TV 한 대 표시:** 웹페이지를 TV 또는 연결된 노트북에서 열어 반별 상태를 확인한다.
5. **TV별 설정과 다중 화면:** 두 대 이상에서 서로 다른 교실을 설정해 각기 올바른 상태가 표시되는지 확인한다.
6. **실시간 전송:** 필요하면 WebSocket을 추가해 순번 변경이 모든 TV에 즉시 반영되도록 한다.

처음부터 학교 전체 서버를 만들 필요는 없다. 노트북 한 대에서 웹 서버, 급식 순서 데이터, Arduino 연결을 함께 실행해 검증한 뒤 교내 서버와 여러 TV로 확장한다.

## 우선 확인할 사항

- 교실 TV의 제조사·모델과 웹 브라우저 사용 가능 여부
- TV에 브라우저가 없거나 호환성이 낮을 때 사용할 PC/미니 PC 유무
- Arduino 보드와 Bluetooth 모듈 모델, 관리 PC의 Bluetooth 지원 여부
- 급식실에서 관리 PC까지의 실제 거리 및 층간·벽 통과 안정성
- 서버 PC와 TV가 같은 교내 네트워크에서 통신할 수 있는지, 학교의 네트워크 연결 정책
- 실제 반 목록, 하루 급식 순서 입력 방식, 순번 되돌리기/수정 등 운영 요구사항
