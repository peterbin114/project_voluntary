# 진행 기록

## 2026-11-10

- 저장소와 프로젝트 문서를 확인하고 Arduino 입력 → 서버 → 교실 TV 안내 화면 구조를 정리함.
- Arduino Uno R4 WiFi의 NEXT 버튼 입력을 Wi-Fi HTTP POST로 서버에 전달하는 스케치를 추가함.
- Python 표준 라이브러리 기반 서버를 추가함. `POST /api/next`로 급식 순서를 진행하고 `GET /api/state`로 현재 상태를 제공함.
- TV 브라우저에서 교실별 URL(`/?classroom=1-2`)로 접속하고 2초 간격으로 서버 상태를 조회해 화면을 갱신하도록 구현함.
- Arduino, 서버, TV 설정 및 실행 방법을 문서화함.
- 코드 변경은 [초안 PR #1](https://github.com/peterbin114/project_voluntary/pull/1)에 있음. 아직 병합되지 않음.
- 실제 Arduino 보드 컴파일과 현장 Wi-Fi/TV 연결은 아직 검증하지 않음.

### 다음 작업
